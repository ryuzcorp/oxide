---
title: WebSocket
description: Keep one WebSocket open and send typed RPC calls through it.
---

Use the WebSocket transport when your app benefits from one long-lived connection. It needs the optional [crossws](https://github.com/h3js/crossws) peer dependency.

WebSocket procedures use the same router as HTTP. Streaming procedures are not supported; calling one returns `INTERNAL_ERROR`.

## Server

```ts twoslash
// @noErrors
import { handle } from "tacho/transport/ws";
import { serve } from "crossws/server";
import { tacho } from "tacho";

const rpc = tacho();
const router = rpc({ ping: rpc.run(() => "pong" as const) });
// ---cut---
serve({
  websocket: handle(router, {
    path: "/rpc",
    sameOrigin: true,
    maxMessageSize: 1_048_576,
    createContext: (peer) => ({
      user: String(peer.context["user"] ?? ""),
    }),
    onError: (error) => console.error(error),
  }),
});
```

| Option           | Meaning                                                             |
| ---------------- | ------------------------------------------------------------------- |
| `path`           | Accept upgrades only at this pathname.                              |
| `createContext`  | Add context before each message is dispatched.                      |
| `onError`        | Observe server errors without exposing internals to the client.     |
| `maxBatchSize`   | Maximum calls in one batch. Default: `20`.                          |
| `maxMessageSize` | Maximum text or binary message size. Default: 1 MB.                 |
| `sameOrigin`     | Reject cross-origin browser upgrades. Default: `false`.             |
| `serializer`     | Replace JSON with a serializer supported by both server and client. |

### Security

A WebSocket connection is not authenticated automatically. `sameOrigin: true` blocks browser upgrades from another site, but it does not identify the user. Verify cookies, tokens, or session data in `createContext` or before the upgrade is accepted.

Keep `maxMessageSize` bounded. Batch limits control the number of calls, while the message limit controls the total bytes parsed from one frame.

## Client

```ts twoslash
import { createClient } from "tacho/client/ws";
import { tacho } from "tacho";

const rpc = tacho();
const router = rpc({ ping: rpc.run(() => "pong" as const) });
type Router = typeof router;
// ---cut---
const client = createClient<Router>({
  url: "ws://localhost:3000/rpc",
  protocols: "tacho",
});

await client.ready;
await client.ping();
client.close();
```

Wait for `.ready` before the first call when connection timing matters. Call `.close()` when the app no longer needs the socket.

| Option       | Meaning                                         |
| ------------ | ----------------------------------------------- |
| `url`        | WebSocket endpoint URL.                         |
| `protocols`  | Value passed to the WebSocket constructor.      |
| `WebSocket`  | Custom constructor; defaults to the global one. |
| `serializer` | The same serializer used by the server.         |
