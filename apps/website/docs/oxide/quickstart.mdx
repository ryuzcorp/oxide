This page shows the recommended setup for oxidejs and the most common workflows, with copy-paste commands.

## Install

```package-install
npm i -D oxidejs
```

```package-install
npm i tacho
```

Extend the TypeScript config:

```json tsconfig.json
{ "extends": "oxidejs/tsconfig" }
```

## Add the plugin

<Tabs>
  <Tab title="Vite">

```ts twoslash vite.config.ts
import { defineConfig } from "vite";
import oxide from "oxidejs/vite";

export default defineConfig({
  plugins: [oxide()],
});
```

Add scripts to `package.json`:

```json package.json
{
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview"
  }
}
```

  </Tab>
  <Tab title="Rsbuild">

```ts twoslash rsbuild.config.ts
// @noErrors
import { defineConfig } from "@rsbuild/core";
import oxide from "oxidejs/rsbuild";

export default defineConfig({
  plugins: [oxide()],
});
```

Add scripts to `package.json`:

```json package.json
{
  "scripts": {
    "dev": "rsbuild dev",
    "build": "rsbuild build",
    "preview": "rsbuild preview"
  }
}
```

  </Tab>
</Tabs>

## Write an entry and an action

```ts twoslash src/server.ts
export default {
  fetch(request: Request) {
    if (new URL(request.url).pathname === "/api/ok") return new Response("ok");
  },
};
```

Return `undefined` to fall through to static files / `index.html`.

```ts twoslash src/test.server.ts
export async function ping() {
  return "pong";
}
```

```ts twoslash src/client.ts
// @filename: test.server.ts
export async function ping() {
  return "pong";
}
// ---cut---
// @filename: client.ts
import { ping } from "./test.server";

console.log(await ping());
//                   ^?
```

`vite dev` and `rsbuild dev` serve `/_action` via middleware. Client imports of `*.server.ts` are stubs. Server and Vite SSR keep the real functions (`import.meta.env.SSR`).

## Build and run

```sh
vite build
node dist/server.js
```

No `index.html` → only `dist/server.js`. With `index.html` → client assets in `dist/client/`.

## Common workflows

### Cloudflare Worker (`celld`)

```ts twoslash
import oxide from "oxidejs/vite";

oxide({
  preset: "celld",
  wrangler: { name: "my-app", compatibility_date: "2026-01-01" },
});
```

`"celld"` skips asset serving (Wrangler `ASSETS` does that) and writes `dist/wrangler.jsonc`.

### Server only

Leave out `index.html`. The plugin emits `dist/server.js` and does not build a client.
