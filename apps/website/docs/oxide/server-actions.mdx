A server action is a function that runs on your server but can be imported and called from browser code. Oxide turns that browser import into a small RPC request. The function body and its server-only imports never enter the client bundle.

Oxide actions use [tacho](/tacho/overview). Install it next to `oxidejs`:

```package-install
npm i tacho
```

## Create your first action

Put server-only code in a file named `*.server.ts`, `*.server.tsx`, `*.server.js`, or `*.server.jsx`. Wrap every remotely callable export in `action()`:

```ts twoslash src/test.server.ts
import { action } from "oxidejs";

export const ping = action(async () => {
  return "pong" as const;
});
```

Then import and call it from client code:

```ts twoslash src/client.ts
// @filename: test.server.ts
import { action } from "oxidejs";
export const ping = action(async () => "pong" as const);
// ---cut---
// @filename: client.ts
import { ping } from "./test.server";

const result = await ping(); // "pong"
```

Oxide replaces that client import with a tacho stub. By default, the stub sends a POST request to `/__oxide/action`. The remote method name is `<file>.<export>`; the example above calls `test.ping`.

## What is exposed?

Only exports written as `export const name = action(...)` become RPC methods. Other values and helpers stay server-only:

```ts twoslash src/users.server.ts
import { action } from "oxidejs";

const normalizeName = (name: string) => name.trim();

export const saveName = action(async (name: string) => {
  return normalizeName(name);
});

export const serverOnlyLabel = "not remotely callable";
```

This explicit marker prevents an exported helper from accidentally becoming a public endpoint. `action()` does not validate input or authorize users. Treat action arguments as untrusted data, validate them, and check the current user before reading or changing private data.

## Reuse authorization and context

Use a higher-order function for action middleware. Keep `action()` as the outer call so Oxide recognizes the export:

```ts twoslash src/profile.server.ts
// @filename: db.ts
export type User = { id: string; role: "user" | "admin" };
export declare const db: {
  users: { findByToken(token: string): Promise<User | undefined> };
  profiles: {
    find(userId: string): Promise<{ name: string } | undefined>;
    update(userId: string, input: { name: string }): Promise<void>;
  };
};
// ---cut---
// @filename: profile.server.ts
import { action, useRequest } from "oxidejs";
import { RpcError } from "tacho";
import { db, type User } from "./db";

function withUser<Args extends unknown[], Result>(
  handler: (user: User, ...args: Args) => Result,
) {
  return async (...args: Args) => {
    const authorization = useRequest().headers.get("authorization");
    if (!authorization) {
      throw new RpcError({ code: -32001, message: "Unauthorized" });
    }

    const user = await db.users.findByToken(authorization);
    if (!user) {
      throw new RpcError({ code: -32001, message: "Unauthorized" });
    }

    return handler(user, ...args);
  };
}

export const profile = action(
  withUser((user) => db.profiles.find(user.id)),
);
```

The client calls `profile()` without supplying `user`. The wrapper reads the request, loads the user, and passes it only to the server handler. Other handler arguments remain typed client input:

```ts
export const update = action(
  withUser((user, name: string) =>
    db.profiles.update(user.id, { name }),
  ),
);
```

Keep authorization wrappers server-only. Throw `RpcError` for an intentional wire error; do not return authentication tokens, database credentials, or other secrets.

## Stream values

Wrap an `async function*` to stream values over [tacho SSE](/tacho/sse-streaming):

```ts twoslash src/ticks.server.ts
import { action } from "oxidejs";

export const ticks = action(async function* (count: number) {
  for (let i = 0; i < count; i++) yield i;
});
```

```ts twoslash src/client-stream.ts
// @filename: ticks.server.ts
import { action } from "oxidejs";
export const ticks = action(async function* (count: number) {
  for (let i = 0; i < count; i++) yield i;
});
// ---cut---
// @filename: client-stream.ts
import { ticks } from "./ticks.server";

const stream = await ticks(3);
for await (const value of stream) console.log(value);
```

Breaking the `for await` loop or calling `await stream.return()` cleans up the server generator. Tacho does not reconnect a dropped stream automatically because repeating the POST could run action side effects twice.

## Cancel a call

Pass `{ signal }` as the final argument. `action()` adds that transport-only argument to the function type. Inside server code, always read the non-optional signal from `useRequest().signal`:

```ts twoslash src/abort.ts
// @filename: test.server.ts
import { action, useRequest } from "oxidejs";

export const ping = action(async () => "pong" as const);
export const ticks = action(async function* (count: number) {
  const { signal } = useRequest();
  for (let i = 0; i < count && !signal.aborted; i++) yield i;
});
// ---cut---
// @filename: abort.ts
import { ping, ticks } from "./test.server";

const controller = new AbortController();
const stream = await ticks(10, { signal: controller.signal });
await ping({ signal: controller.signal });
controller.abort();
```

Inside the action, `useRequest().signal` follows the same abort.

## Read request context

### `useRequest()`

`useRequest()` returns the current server `Request` in actions, SSR, and frame renders. It throws outside request handling:

```ts twoslash src/who.server.ts
import { action, useRequest } from "oxidejs";

export const who = action(async () => {
  return useRequest().headers.get("x-user");
});
```

### `useCtx()`

`useCtx()` returns tacho context: `{ req }` plus values added by middleware or `createContext`:

```ts twoslash src/me.server.ts
import { action, useCtx } from "oxidejs";

export const me = action(async () => {
  return useCtx<{ req: Request; user?: string }>().user;
});
```

### `useEnv()` and `useFetchCtx()`

With [`preset: "celld"`](/oxide/configuration#preset), these return the Worker `env` and execution context from `fetch(request, env, ctx)`. They are `undefined` on the Node fetch preset.

```ts twoslash src/env.server.ts
import { action, useEnv, useFetchCtx } from "oxidejs";

type Env = { API_URL: string };

export const hasApi = action(async () => {
  useFetchCtx()?.waitUntil?.(Promise.resolve());
  return Boolean(useEnv<Env>()?.API_URL);
});
```

Do not return secrets from an action. Anything returned by an action is sent to the caller.

## Change the transport or path

HTTP is the default. The endpoint is `/__oxide/action`, and same-origin protection is on:

```ts twoslash
import oxide from "oxidejs/vite";

oxide({
  actions: {
    path: "/rpc",
    sameOrigin: true,
  },
});
```

Use `transport: "ws"` for WebSocket actions. Install `crossws`; WebSockets do not work with [`preset: "celld"`](/oxide/configuration#preset).

```ts twoslash
import oxide from "oxidejs/vite";

oxide({
  actions: { transport: "ws", path: "/rpc" },
});
```

Set `sameOrigin: false` only when you intentionally accept calls from another origin and provide your own CORS, CSRF, and authentication rules.

For static HTTP headers, use [`actionHeaders`](/oxide/configuration#actionheaders). Remember that values are shipped to the browser, so never place a private server secret there.
