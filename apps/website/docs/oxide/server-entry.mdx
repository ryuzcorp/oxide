description: Handle a request in your server entry, or skip it and let static files take over.
---

Every request hits this file first. The default path is [`src/server.ts`](/oxide/configuration#workerentry). Export a `fetch` that takes the request and returns a response.

```ts twoslash src/server.ts
export default {
  fetch(request: Request) {
    if (new URL(request.url).pathname === "/api/ok") {
      return new Response("ok");
    }
  },
};
```

If `fetch` returns nothing, `oxidejs` keeps going. With a page in the project, that means a matching static file, then `index.html`. Without a page, the build is only the server bundle - there is nothing to fall through to.

To serve typed RPC from this file, set up a tacho router and pass it to `handle()`. See the [Tacho quickstart](/tacho/quickstart).
