When [`src/server.ts`](/oxide/configuration#workerentry) exists, requests reach that entry after middleware and actions. Export a `fetch` — named or on the default export. Missing the default path is fine: Oxide still serves actions and static assets. On [`preset: "worker"`](/oxide/configuration#preset) the runtime also passes Worker `env` and `ctx`, the same pair actions read with [`useEnv()` / `useFetchCtx()`](/oxide/server-actions#useenv-and-usefetchctx).

Type it with [`FetchHandler`](#fetchhandler):

```ts twoslash src/server.ts
import type { FetchHandler } from "oxidejs";

type Env = { SECRET?: string };

export const fetch = ((request, _env, ctx) => {
  if (new URL(request.url).pathname === "/api/ok") {
    ctx.waitUntil?.(Promise.resolve(null));
    return new Response("ok");
  }
  return;
}) satisfies FetchHandler<Env>;
```

Bare `return` (or `undefined`) means fall through. With a page in the project, Oxide tries a matching static file, then `index.html` for navigations (`Sec-Fetch-Dest: document` or `Accept: text/html`). A fetch for `/missing.js` stays `404` — not a silent SPA rewrite.

`export default { fetch }` works when you prefer an object entry (or need `scheduled` / `queue` on the default for Cloudflare Workers mode). If both a default `fetch` and a named `fetch` exist, the default wins.

On Node, `public/` is copied next to the client. Hashed assets get `Cache-Control: immutable` and `ETag` / `304`. `index.html` is `no-cache`. Without a page, the build is only the server bundle — there is nothing to fall through to.

Named exports such as `scheduled` and `queue` are re-exported (`export *`). Put them on `export default { … }` as well when the host only reads the default.

On Node the generated server handles `SIGTERM` / `SIGINT`: stop accepting connections, drain in-flight requests, force exit after 5 seconds.

## `FetchHandler`

```ts twoslash
import type { FetchHandler } from "oxidejs";

// request, env, ctx — return Response, or fall through with bare `return`
declare const fetch: FetchHandler<{ SECRET?: string }>;
```

`Env` defaults to a JSON-compatible binding bag. Pass your Worker / [`env`](/oxide/configuration#env) shape as the type argument. The wrapper always supplies `env` and `ctx`.

Prefer `satisfies FetchHandler<Env>` so parameters pick up types without annotations. Under `noImplicitReturns`, use a bare `return` when you want fallthrough.

## `ServerEntry`

```ts twoslash
import type { FetchHandler, ServerEntry } from "oxidejs";

type Env = { SECRET?: string };

declare const fetch: FetchHandler<Env>;
declare const entry: ServerEntry<Env>;
```

Object form:

```ts twoslash
import type { FetchHandler, ServerEntry } from "oxidejs";

type Env = { SECRET?: string };

const fetch = ((request, _env) => {
  if (new URL(request.url).pathname === "/api/ok") {
    return new Response("ok");
  }
  return;
}) satisfies FetchHandler<Env>;

export default { fetch } satisfies ServerEntry<Env>;
```
